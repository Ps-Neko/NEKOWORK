## Problem Statement

현재 라이브(Phase 1.0, `?fixture=sample-pr-001`)는 **정적 화면** + `"AI 의견은 판정이 아니다"`(opinion vs rule) wedge 헤더다. 두 가지 갭:

1. **"CI랑 뭐 다름?" 취약** — "rule + CI"는 경쟁사(Cursor/Claude Code/Codex)도 갖고 있어, opinion-vs-rule 후크만으로는 차별이 1초에 안 박힌다. (선행 doc이 *최악의 objection*으로 예측한 지점.)
2. **추상성** — The Assignment 5명이 전원 *개인*이라, "AI 의견 ≠ 판정"이라는 추상 명제보다 **"내가 실제로 겪는 워크플로우"**가 더 체감된다.

→ hero를 **"개인 개발자의 실제 워크플로우 + 검증 공백"**으로 재설계하고, NEKOWORK가 그 공백에 끼어드는 모습을 **Before/After 토글**로 보여준다. 기존 자산(충돌 비교·12단계·증거)과 다크테마·기술스택은 유지.

이 리빌드는 선행 doc의 **메시지 레이어 재설계**이며, 그 doc의 핵심 통찰(Codex cold read: "12 stations가 killer가 아니라 *LGTM 충돌*이 killer")을 **워크플로우 맥락에서 강화**한다.

## 페이지 구조

```
① HERO (신규)          ← 워크플로우 토글
   ↓ "왜 막았지?"
② 같은 코드, 다른 결론   ← 기존 renderConflictFrame 재활용
   ↓ "어떻게?"
③ 12단계 검증 그리드     ← 기존 renderStationGrid (변경 없음)
   ↓ "증거는?"
④ Evidence trail        ← 기존 renderEvidenceTrail (변경 없음)
```

현재의 별도 **PR summary 섹션은 제거**하고, PR 식별(어떤 PR인지) 한 줄을 ②충돌 비교 헤더로 흡수한다. (hero가 이미 "내 코드 → PR → …" 흐름을 보여주므로 별도 PR 요약은 중복.)

## HERO 상세 (확정 카피)

- **eyebrow**: `AI가 코드를 쏟아내는 시대 — 검증만 사람 손에 남았다`
- **타이틀**: `내 AI가 짠 코드를, 내 AI가 "괜찮다"고 통과시켰다.`
- **서브**: `사람이 진짜 본 적은 없는데, 그대로 배포된다.`
- **토글**: `[ NEKOWORK 없이 (지금) ]  [ NEKOWORK 켜기 ]`
- **Before (기본/off)**: `내 코드 → PR → AI ✓ LGTM → 머지 → 🚢 배포`
  - 캡션(bad): `🔴 검증 0인 채로 세상에 나간다.`
- **After (on)**: `내 코드 → AI ✓ LGTM → ⚡ NEKOWORK ✗ BLOCK → 사람 결정`
  - 캡션(good): `✓ 같은 코드인데 막혔다 — 의견이 아니라 규칙으로 판정한다.`
- **스크롤 힌트**: `↓ 왜 막았는지 보기`

### 토글 동작

- 2-state. 기본 = Before(off). 클릭 시 흐름도 + 캡션 교체.
- 상태는 in-memory (URL에 안 실음). 기존 `?fixture=` 쿼리는 유지.
- **a11y**: 두 버튼 `aria-pressed`, 키보드 포커스 + Enter/Space, `prefers-reduced-motion` 시 전환 애니메이션 제거.

## 인터랙션 / a11y / 모바일

- 토글 버튼: `aria-pressed` + 키보드 + 포커스 링.
- 흐름도 박스: 의미 라벨(`aria-label` 또는 sr-only)로 스크린리더가 단계 인지.
- `prefers-reduced-motion: reduce` honor (기존 패턴 유지).
- 모바일 320px: 흐름도 `flex-wrap`, `overflow-x` 방지 (기존 패턴 유지).

## 테스트 / CI 영향

- `tests/a11y.test.ts`: hero 토글 버튼 axe 통과 + Before/After **양 상태** 모두 axe. 토글 클릭 시 After 흐름 표시 검증(playwright) 추가.
- `scripts/gen-hero-gif.ts`: hero 변경 → GIF 재생성. **Before→After 전환 2컷**으로 동작을 GIF에 담음. `< 5MB` 유지, 한글 폰트(fonts-noto-cjk) 정상.
- `lighthouserc.json` / deploy: 변경 없음 (FCP/LCP 기존 통과 유지).

## VISION.md UI 침해 체크 (P5 — "LLM 의견은 verdict가 아니다" 침해 0 유지)

- After에서 **NEKOWORK = verdict(BLOCK)**, **AI = advisor(LGTM, 의견)**으로 명확 분리 → opinion≠verdict가 *오히려 강화*된다.
- `decision.json`의 verdict가 hero After의 1차 시각 대상.
- AI의 "LGTM"은 *판정처럼* 보이지 않고 **문제의 일부**("AI가 통과시켰다")로 제시된다.

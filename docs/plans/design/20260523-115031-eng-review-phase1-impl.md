## Edge Cases

- **모바일 viewport (320px iPhone SE)**: 12-station grid 가 horizontal scroll 없이 표시. tap target ≥44×44px.
- **prefers-reduced-motion: reduce**: timeline 의 station 전환 애니메이션 비활성화. CSS media query honor.
- **한국어 폰트 fallback (playwright headless)**: ubuntu CI 의 `fonts-noto-cjk` 로 한글 렌더링 정상. tofu (사각 박스) 발생 시 hero GIF 시각 회귀. _구체 검증 방법론은 첫 CI run 후 결정 — playwright 의 `document.fonts.check('1em Noto Sans CJK KR')` 어서션 + screenshot baseline 비교 권장 (RESIDUAL: Reviewer Concerns)._
- **screen reader (NVDA/VoiceOver)**: 각 station 의 aria-label 음성 출력 정상 ("station 1 of 12, Preverify, status: pass").
- **GitHub Pages base path 누락**: `<base>` 태그 또는 vite.config.ts 의 `base: '/NEKOWORK/'` 누락 시 asset 404. PR preview 단계에서 검증.
- **npm publish 실수**: `.npmignore` 누락 시 visualizer 가 npm 패키지 포함됨 → 30-50MB 부풀음. CI 의 `npm pack --dry-run` assertion 으로 unpackedSize delta < 1MB 검증.
